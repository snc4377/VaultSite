Note title: MEOW

- Connect to the VPN using OpenVPN: `openvpn nombre_vpn`
- Run an nmap scan to identify open ports
- Use telnet to access the machine: `telnet ip_maquina`, then log in as the root user (no password required)
- Run `ls` to view the directory contents and locate a file named `flag.txt`
- Execute it with `cat` to retrieve the root flag
