Impacket also includes the tool [raiseChild.py](https://github.com/SecureAuthCorp/impacket/blob/master/examples/raiseChild.py), which automates the escalation from a child domain to a parent domain. We need to specify the target domain controller and the credentials of an administrative user in the child domain; the script will handle the rest. If we examine the output, we see it starts by enumerating the fully qualified domain names (FQDN) of both the child and parent domains. Then:

- Retrieves the SID for the Enterprise Admins group in the parent domain
- Obtains the hash of the KRBTGT account in the child domain
- Creates a Golden Ticket
- Logs into the parent domain
- Retrieves the credentials of the Administrator account in the parent domain
