Nowadays, most modern web and mobile applications work by continuously connecting to back-end servers to send and receive data, then processing this data on the user's device, such as their web browsers or mobile phones. Since most applications heavily rely on back-end servers for data processing, testing and securing back-end servers is becoming increasingly important.

Testing web requests to back-end servers constitutes the majority of Web Application Penetration Testing, which includes concepts that apply to both web and mobile applications. To capture the requests and traffic passing between applications and back-end servers and manipulate these requests for testing purposes, we need to use `Web Proxies`.

---

## What Are Web Proxies?

Web proxies are specialized tools that can be configured between a browser/mobile app and a back-end server to capture and view all web requests sent between both ends, essentially acting as man-in-the-middle (MITM) tools. While other `Network Sniffing` applications, like Wireshark, operate by analyzing all local traffic to see what's passing through a network, web proxies primarily work with web ports such as `HTTP/80` and `HTTPS/443`, among others.

Web proxies are considered one of the most essential tools for any web pentester. They significantly simplify the process of capturing and replaying web requests compared to older CLI-based tools. Once a web proxy is set up, we can view all HTTP requests made by an application and all responses sent by the back-end server. Additionally, we can intercept a specific request to modify its data and see how the back-end server handles it, which is an essential part of any web penetration test.

---

## Uses of Web Proxies

Although the primary use of web proxies is capturing and replaying HTTP requests, they have many other features that enable different uses. The following list shows some of the other tasks we can use web proxies for:

- Web application vulnerability scanning
- Web fuzzing
- Web crawling
- Web application mapping
- Web request analysis
- Web configuration testing
- Code reviews

In this module, we won't discuss any specific web attacks, as other HTB Academy web modules cover various web attacks. However, we will thoroughly cover how to use web proxies and their various features, mentioning which types of web attacks require which features. We'll be covering the two most common web proxy tools: `Burp Suite` and `ZAP`.

---

## Burp Suite

[Burp Suite (Burp)](https://portswigger.net/burp) —pronounced "Burp Swit"— is the most common web proxy for web penetration testing. It has an excellent user interface for its various features and even provides a built-in Chromium browser for testing web applications. Certain Burp features are only available in the commercial `Burp Pro/Enterprise` version, but even the free version is an extremely powerful testing tool to keep in our arsenal.

Some of the `paid-only` features are:

- Active web application scanner
- Fast Burp Intruder
- The ability to load certain Burp Extensions

The `free` community version of Burp Suite should be sufficient for most pentesters. Once we start with more advanced web application penetration testing, the `pro` features may become useful. Most features we'll cover in this module are available in the `free` community version of Burp Suite, but we'll also address some `pro` features, like the Active Web App Scanner.

**Tip:** If you have an educational or business email address, you can request a free trial of Burp Pro at this [link](https://portswigger.net/burp/pro/trial) to follow some of the exclusive Burp Pro features shown later in this module.

## OWASP Zed Attack Proxy (ZAP)

[OWASP Zed Attack Proxy (ZAP)](https://www.zaproxy.org/) is another common web proxy tool for web penetration testing. ZAP is a free and open-source project initiated by the [Open Web Application Security Project (OWASP)](https://owasp.org/) and maintained by the community, so it has no exclusive paid features like Burp. It has grown significantly in recent years and is quickly gaining recognition in the market as the leading open-source web proxy tool.

Like Burp, ZAP provides various basic and advanced features that can be used for web pentesting. ZAP also has certain strengths over Burp, which we'll cover throughout this module. The main advantage of ZAP over Burp is that it's a free and open-source project, meaning we won't face any throttling or restrictions in our scans that are only removed with a paid subscription. Additionally, with a growing community of contributors, ZAP is gaining many of the features that are paid-only in Burp—for free.

In the end, learning both tools can be quite similar and will provide us with options for every situation during a web pentest. We can choose to use the one we find most suitable for our needs. In some cases, we may not see enough value to justify a paid Burp subscription and can switch to ZAP for a completely open and free experience. In other situations where we want a more mature solution for advanced pentesting or corporate pentesting, we may find the value provided by Burp Pro justified and can switch to Burp for these features.
