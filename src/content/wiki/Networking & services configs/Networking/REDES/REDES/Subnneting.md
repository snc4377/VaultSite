Note title: Subnneting

We go to this page https://www.calculator.net/ip-subnet-calculator.html If we scroll down a bit, we see a table that's very useful for determining hosts and everything.
![Pasted image 20231007135337](/VaultSite/wiki-images/Pasted%20image%2020231007135337.png)

Once we've decided on the number of HOSTS we want in our network, meaning all the IPs we want to assign per subnet, we select the IP we want to use for calculating the subnets and the subnet mask we chose earlier.
![Pasted image 20231007135538](/VaultSite/wiki-images/Pasted%20image%2020231007135538.png)

It will automatically calculate the possible subnets and their respective ranges.
