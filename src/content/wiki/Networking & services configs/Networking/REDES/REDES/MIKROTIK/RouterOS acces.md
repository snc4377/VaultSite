Note title: RouterOS Access

We can access by MAC or IP. To access by IP, we need to set the router's IP on our network adapter, but to gain access we must physically reset the router (if we don't have access). To reset it, first press the reset button, then connect the power supply, and wait until the USR LED blinks. Then we can connect the cable to configure the router.
