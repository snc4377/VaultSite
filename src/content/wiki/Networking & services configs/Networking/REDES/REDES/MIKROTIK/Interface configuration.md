# Interface Configuration

To configure IP addresses and other settings for interfaces, go to IP>ADDRESSES
![Pasted image 20231016133045](/VaultSite/wiki-images/Pasted%20image%2020231016133045.png)

![Pasted image 20231016133058](/VaultSite/wiki-images/Pasted%20image%2020231016133058.png)

All interfaces will now be displayed. In the network section, we need to enter the interface's IP address and netmask, but the netmask must be in CIDR notation, e.g., /16.
![Pasted image 20231016133221](/VaultSite/wiki-images/Pasted%20image%2020231016133221.png)
