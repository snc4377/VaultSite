Note title: CAPSH

**Capsh** (Capability Shell Wrapper) is a command-line tool in Linux systems designed to **explore, test, and debug Linux "capabilities"**. It functions as a shell wrapper that can increase or decrease the capabilities of a process or user without requiring full root access, serving as both a security and administration tool.
