# Shell and Reverse Shell

A shell is how you communicate with the computer, either by typing text commands or interacting with visual elements. It's the tool that allows issuing instructions and performing tasks.  
CLI (Command Line Interface shell)

A reverse shell is when a remote machine establishes a connection and sends commands to a local machine.
