# BRAND IDENTITY & DESIGN SYSTEM

## 1. User Profile
- **Role:** Cybersecurity Student & Ethical Hacker.
- **Vibe:** "Hacker Wiki", Terminal-based, minimalist, highly technical but professional.
- **Objective:** Showcase projects (HTB, CTFs), document knowledge (Obsidian Wiki), and share cybersecurity news.

## 2. Visual Style (The "Hacker" Aesthetic)
- **Theme:** Strictly Dark Mode. 
- **Background:** Deep matte black (`#0a0a0a`) or very dark grey (`#111111`).
- **Primary Text:** Off-white (`#e0e0e0`) for readability.
- **Accent Color:** Terminal Green (`#00ff41`) or Cyber Cyan (`#00e5ff`) for links, hover states, and highlights.
- **Typography:** 
  - Headings/Code: Use a monospace font (like 'JetBrains Mono', 'Fira Code', or 'Courier').
  - Body: A clean sans-serif (like 'Inter' or 'Roboto') for easy reading.
- **UI Elements:** Use subtle borders, terminal-like blocks, and minimal animations (like a typing cursor effect or subtle glow on hover).

## 3. Page Architecture
- **Home:** Hero section with a terminal-style greeting (e.g., `user@cyber:~$ whoami`), a brief bio, and prominent links (GitHub, LinkedIn, Hack The Box).
- **Portfolio:** A grid of project cards. Cards should look like file directories or terminal outputs.
- **Wiki:** A clean, readable documentation layout for Markdown files. Sidebar navigation.
- **Blog:** Chronological feed of news, styled like a hacker's log or a series of terminal outputs.
